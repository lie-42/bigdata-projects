## 2. 풀고 싶은 문제

> **졸린 얼굴 이미지 데이터로, 사람의 얼굴에서 졸음 여부를 이진 분류하고 싶다.**

- **예측/분류 대상(target):** 졸린 상태(DROWSY) vs 일반 상태(NATURAL)
- 실시간 카메라 영상에서 프레임을 추출하여 매 프레임마다 졸음 여부를 예측

---

## 3. 만들 서비스 (완성 모습)

**방식:** 딥러닝 (CNN 기반 이진 분류)

### 입력 → 출력

| 입력 | 출력 |
|------|------|
| 웹캠 / 카메라 실시간 영상 | "졸음 감지!" 경고 알림 |

### 서비스 시나리오 (택1 또는 확장)

**[시나리오 A] 블랙박스 연동 졸음 경보기**
- 차량 내 카메라가 운전자 얼굴을 실시간 촬영
- 졸음 감지 시 → 경고음 + 화면 알림 출력
- 졸음 운전 사고 예방 목적

**[시나리오 B] 스마트폰 쇼츠 차단 앱**
- 전면 카메라로 사용자 얼굴 모니터링
- 졸린 상태 감지 시 → 앱 자동 잠금 또는 영상 일시정지
- 수면 부족 상태에서의 스마트폰 과사용 방지

---

## 4. 예상 난관

**실시간 영상 처리 + 낮은 지연(latency) 확보**

- 카메라에서 프레임을 캡처하고 모델 추론까지 매 프레임마다 수행해야 함
- GPU 없는 환경에서는 추론 속도가 느려 실시간성이 깨질 수 있음
- OpenCV로 프레임을 추출하고 경량 모델(MobileNet 등)을 활용하거나,  
  매 N번째 프레임만 추론하는 방식으로 성능을 절충할 예정
